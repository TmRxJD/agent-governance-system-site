1. Contact TmRxJD for a **commercial license** to `@tmrxjd/agent-governance-system`.
2. After payment, you receive GitHub / Packages access (invite or org team).

4. Configure consumer `.npmrc` (see [install-commercial](../docs/install-commercial.html)).
