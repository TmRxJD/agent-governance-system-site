Agent Governance System

Architecture overview

AGS is a mechanics-agnostic governance stack for AI agents: commit authorization (CAP), atomic staging scopes, schema/pointer/semantic muscles, testing & performance suites, and sentinel reflexes — including dual-license enforcement.
