# Tower Community Access

Eligible **The Tower** community members may use AGS under the **Tower Community License**
(`LICENSE.TOWER`): free, **non-commercial**, Tower-related local use only.

## Eligibility (examples)

- Players of The Tower
- Modders, wiki contributors, community tool authors
- Tower SDK users building Tower tools for yourself or the community

## How to get install access

1. Request a community grant (process TBD — private repo has a placeholder script).
2. Accept the invite to the private package.
3. Follow [Tower install](../docs/install-tower.html).

Commercial products must use the [paid commercial path](../buy/).
